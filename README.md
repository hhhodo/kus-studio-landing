# 결 (GYEOL) — 라이프스타일 오브젝트 랜딩페이지

**Live: https://hhhodo.github.io/kus-studio-landing/**

[mikekus.com](https://mikekus.com/)의 레이아웃 구조(허브리드 히어로 → 4카드 하이라이트 → 커뮤니티 →
카테고리 리스트 → 후기 → CTA → 푸터)와 `styles.css`(디자인 토큰) + `CHEATSHEET_16.md`(작성용 단일
참조 요약)의 규칙만 그대로 가져오고, **텍스트·브랜드·콘텐츠는 전부 가상의 한국어 라이프스타일 제품/
이커머스 브랜드 "결(GYEOL)"로 새로 썼습니다.** Mike Kus 디자인 스튜디오의 실제 카피나 클라이언트
정보는 남아있지 않습니다 — 리포지토리 이름(`kus-studio-landing`)만 이전 이력이라 유지했습니다.

"결"은 나뭇결·물결처럼 사물과 하루가 가진 고유한 질감·흐름을 뜻하는 순우리말로, "결이 다르다"(결이
좋다/남다르다)는 관용구를 브랜드 카피 전반에 녹였습니다.

## 이미지

`.img` 회색 placeholder 대신 실제 라이프스타일 사진을 사용했습니다. 실제 제품 사진이 없어
[Picsum Photos](https://picsum.photos)(Unsplash 소스, 자유 이용 라이선스)에서 분위기가 맞는 7장을
`assets/photos/`에 내려받아 제품·배경 컨텍스트에 맞게 배치했습니다 — 실제 판매 제품이 아닌 가상
브랜드의 자리채움용 이미지임을 밝힙니다. "이미지 비중=높음" 변주에 맞춰 Hero·Work뿐 아니라
Community·Contact도 이미지 배경(다크 오버레이 0.55~0.6 + 인버스 텍스트)으로 채워서, 순수 텍스트만
남은 섹션은 Categories·Testimonial 둘뿐입니다.

| 위치 | 이미지 | 매칭한 제품/맥락 |
|---|---|---|
| 히어로 | 가파른 언덕에 형형색색 건물이 늘어선 해안 마을 | 브랜드 무드 |
| 제품 1 | 고요한 호수 위 요트 (모노톤) | 캔버스 세일 백 · 트래블 굿즈 |
| 제품 2 | 책상 위 스마트폰 클로즈업 | 오크 데스크 오거나이저 · 스테이셔너리 |
| 제품 3 | 여름 해변을 즐기는 사람들 | 리넨 비치 타월 · 텍스타일 |
| 제품 4 | 노을 진 바다 위로 날아오르는 새들 | 드리프트우드 캔들 · 프래그런스 |
| 커뮤니티 (배경) | 사람들로 붐비는 기차역 대합실 | 일상 속 다양한 사람들 |
| Contact (배경) | 안개 낀 바다 | 무드/클로징 |

## 이번 변주(Variant) 설정

첫 줄 코드 주석: `<!-- variant: typo=loud / image=높음 / color=accent / radius=sharp / border=outlined -->`

| 축 | 값 | 근거 |
|---|---|---|
| 타이포그래피 태도 | `loud` | "매일 똑같던 하루, 결이 달라집니다" — 단정적 브랜드 선언. 히어로 `display-md`, 섹션 헤드라인 `h0` |
| 이미지 비중 | `높음` | 라이프스타일 제품 브랜드 특성상 사진이 콘텐츠의 핵심. 히어로 비주얼·워크 그리드·커뮤니티·Contact 4곳이 `.container` 밖 풀블리드/이미지 배경 |
| 섹션 너비 | 전 섹션 풀블리드 | `.container`에서 `max-width` 캡을 아예 제거 — 좌우 `--gutter`(80/40/20)만 남기고 모든 섹션이 뷰포트 폭 그대로 간다. 줄길이는 섹션 폭이 아니라 본문 문단에 직접 건 `--measure`(42ch)로만 제어 |
| 컬러 모드 | `accent` | 참고한 mikekus.com 실제 CSS(`--framer-link-text-color:#09f`, 아이콘 마스크 `#06f`)에서 추출한 블루를 브랜드 컬러로 채택. `--color-brand:#0066ff` 등 토큰을 `:root` 상단에 추가하고 칩·CTA 버튼·hover·이미지 프레임 라인에만 사용 — 본문/헤드라인 텍스트는 계속 그레이스케일 |
| 라운드 | `sharp` | 모서리 전부 각짐(`--radius-0`) — 무난함에 타협하지 않는다는 브랜드 태도 |
| 보더 | `outlined` | 구조 구분선은 `--border-1`(중립), 이미지 프레임·카드는 브랜드 라인(`--color-brand-line`), CTA는 브랜드 배경 — 정교하게 구획된 제품 그리드 인상 |

## 참고한 원본과의 차이

- **화살표 등 페이지 이동 요소 전부 제거**: 캐러셀·페이지네이션·이전/다음 버튼 없음, 카드마다
  있던 "자세히 보기" 류 링크도 없음 — 존재하지 않는 하위 페이지로 이동하는 것처럼 보이기 때문.
  남긴 액션은 상단 nav(같은 페이지 내 스크롤)와 Contact의 "제품 보러 가기"(같은 페이지 앵커),
  이메일뿐. 모달·아코디언 없음, 전체가 한 페이지 스크롤로 구성.
- **텍스트·콘텐츠 전체를 가상 브랜드로 재작성**: 디자인 스튜디오(브랜딩/웹디자인/일러스트/포토그래피
  서비스, 클라이언트 후기)였던 원본 구조를, 리빙·라이프스타일 오브젝트를 파는 이커머스 브랜드
  (제품 하이라이트, 제품 카테고리, 구매 후기)로 완전히 바꿨습니다.

## Structure

```
index.html          메인 페이지 1개 (Hero → Product Highlights → Community → Categories → Testimonial → Contact → Footer)
css/style.css        디자인 토큰(styles.css 원본) + 컴포넌트 스타일
js/main.js           스크롤 리빌(IntersectionObserver), reduced-motion 대응
assets/favicon.svg   파비콘 ("결" — 결/물결 모티프, 그레이스케일 + 브랜드 블루)
assets/photos/       히어로·제품·배경용 라이프스타일 사진 7장
```

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 배포

`main` 브랜치에 push하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
저장소 Settings → Pages → Source가 "GitHub Actions"로 설정되어 있어야 합니다.
